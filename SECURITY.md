# Security policy

Report a suspected vulnerability privately to WebmasterID through the support
channel of your WebmasterID account, or GitHub's "Report a vulnerability" on this
repository. Please do not open a public issue for a security problem, and do not
include real user identifiers, account keys or production app property ids.

In scope: the two binary frameworks published here and this package manifest.
The SDK holds no secret: the app property id is public configuration.
